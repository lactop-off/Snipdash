# 基本設計 — 「今日」横断タスクビュー

> フェーズ: 基本設計 (designer) ／ feature slug: `today-view`

## 決定事項（オーナー承認済み）
- 表示形態: **右サイドパネル**（盤面を見ながら消化）
- 集約範囲: **期限切れ(overdue) ＋ 今日(当日〜23:59) ＋ まもなく(soon)**
- 追加要素: **なし**（シンプル優先。soon 閾値は既定1時間固定、期限なし/今日完了は出さない）

## レイアウト
ツールバー右の **トグルボタン**（lucide `calendar-check` ＋ 未消化件数バッジ）で右ドロワーを開閉。

```
┌── toolbar ───────────────── [📅3] ✏️ ⚙ ┐   ← トグル(件数バッジ)
│ boards / canvas        │  今日           × │  ← 右パネル(幅320, 全高)
│                        │  ── 期限切れ ──   │
│                        │  ◯ 返信メール      │
│                        │     営業 · 13:00   │  ← 本文 / 所属(カード·盤面) / 期限pill
│                        │  ── 今日 ──        │
│                        │  ◯ 日報の作成      │
│                        │  ── まもなく ──    │
│                        │  ◯ MTG 準備        │
└────────────────────────┴───────────────────┘
```

- 右からスライドイン（`transform: translateX`）。盤面はオーバーレイで隠さない（薄い左シャドウのみ）。
- ヘッダー: タイトル「今日」＋閉じる(`x`)。本体は縦スクロール。
- セクション順: **期限切れ → 今日 → まもなく**。空セクションは非表示。全件0なら空状態（「今日やることはありません 🎉」）。

## 行の仕様
`[ 丸チェック ][ 本文テキスト ][ 所属: カード名 · 盤面名(muted, 小) ][ 期限pill(`clock`+時刻) ]`
- **丸チェック**: 既存 todo の iOS 風丸チェック(`.todo-check`)を流用。押すと `done` トグル → 当該行はビューから消える。
- **行(本文)クリック**: 該当**盤面へ切替**＋対象カードを **1.5秒フラッシュ**して視認可能に（パネルは開いたまま）。
- 期限切れ行は danger 寄りの色アクセント、今日/まもなくは通常。

## アイコン（lucide / Iconify）
- トグル: `calendar-check`（新規取得）
- 閉じる: `x`（取得済み）
- 期限pill: `clock`（取得済み）

## 文言（ja / en）
- `today.title`: 今日 / Today
- `today.section.overdue`: 期限切れ / Overdue
- `today.section.today`: 今日 / Today
- `today.section.soon`: まもなく / Soon
- `today.empty`: 今日やることはありません 🎉 / Nothing due today 🎉
- `today.open` (aria/tooltip): 今日のタスク / Today's tasks

## アクセシビリティ
- パネルは `role="complementary"`、トグルは `aria-label`＋`aria-expanded`。
- **Esc で閉じる**（既存のグローバル Esc ハンドラに統合）。

## 設計レビュー観点（QA / tech-lead 向け）
- 既存パターン（カードヘッダー、`card-action`、丸チェック、`clock` pill）と一貫しているか。
- アイコン名は実在の lucide 名か（`calendar-check` を確認）。
- 盤面が右に寄ることで grid の幅計算に影響しないか（パネルは canvas の上に重ねる／flex を圧迫しない設計）。
