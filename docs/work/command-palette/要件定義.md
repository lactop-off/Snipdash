# 要件定義 — コマンドパレット（Ctrl+K）

> フェーズ: 要件定義 (pm) ／ 状態: **人間承認待ち** ／ feature slug: `command-palette`

## ゴール & ユーザー価値
どの盤面にいても **Ctrl+K** で全カード/盤面を横断検索し、**即コピー or ジャンプ**できる。盤面・カードが増えても目的のスニペット/タスクに最短到達する「作業中の入り口」。

## スコープ
**In scope**
- `Ctrl+K`（Mac は `Cmd+K`）でパレットをオーバーレイ表示。入力でファジー絞り込み、↑↓選択、Enter実行、Escで閉じる、クリックでも実行。
- 検索対象: 全盤面のカード（**label ＋ 本文**：text body / markdown source / code source / todo 各項目テキスト）と、**盤面(boards)名**。
- 各候補に「種別アイコン｜タイトル（label もしくは抜粋）｜所属盤面名」を表示。
- 実行（既定アクション）: カード＝コピー可能(text/markdown/code)なら**コピー**、それ以外(todo等)は**ジャンプ**。盤面＝その盤面へ**切替**。ジャンプ時は対象カードを一瞬ハイライト（既存 `flashCard`）。
- コピー時は `{{変数}}` を展開（既存 `copyResolved`）。

**Out of scope（今回）**
- 検索履歴 / お気に入り / 最近使った。
- 正規表現・高度なクエリ構文。
- カード新規作成や本文編集（パレットからは到達のみ）。

## 機能要件 (FR)
- **FR-1** `Ctrl/Cmd+K` でパレットを開閉（入力欄にフォーカス中でもグローバルに開ける）。
- **FR-2** 入力に対し**ファジー一致**で候補を絞る（label を優先スコア、本文一致も拾う）。依存追加なしの軽量自前実装で O(n)。
- **FR-3** 候補表示: 種別アイコン＋タイトル＋所属盤面。本文ヒット時はマッチ周辺の抜粋を出せると望ましい。
- **FR-4** ↑↓で選択移動、Enterで実行、Escで閉じる、マウスクリックでも実行。開いた直後は検索入力にフォーカス。
- **FR-5** 既定アクション＝上記（コピー可ならコピー / それ以外ジャンプ）。**代替アクション**（コピーとジャンプの逆）も実行できる手段を用意（→ Q3）。
- **FR-6** 盤面候補はジャンプ（`setActiveBoard`）。
- **FR-7** 空入力時の表示は要決定（→ Q4）。
- **FR-8** ja/en 両対応（プレースホルダ・空状態・種別ラベル）。

## 受け入れ基準 / DoD
- `pnpm typecheck` / 該当テスト（検索ロジックの単体）/ `build:vite` が通る。
- `Ctrl+K` で開き、入力で候補が正しく絞られる（label・本文の両方でヒット）。
- Enter でカードはコピー（変数展開込み）/ 盤面はジャンプ。代替操作でもう一方も可能。
- Esc で閉じる。0件時に空状態。ja/en で表示。
- **実機検証（QA/Playwright）**：Ctrl+K→入力→候補絞り込み→Enterでコピー（クリップボード確認）→盤面検索→Enterでジャンプ（盤面切替）→Esc、を観察。
- 非Tauriデモパスでも動作。

## 制約
- **新規スキーマ不要**（既存データを読むだけ）。Rust 変更なし・lockstep 非抵触の見込み。
- 検索/スコアリングは SDK の純粋関数に分離して**単体テスト**を付ける（logic-layer 規約）。
- i18n、最小権限、デモパス維持。

## 人間（オーナー）への Open Questions
1. **検索対象に本文を含める**か（推奨: label＋本文。強力だがヒットが増える）。labelのみに絞る選択肢も。
2. **アプリ操作コマンド**（編集/使用モード切替・今日を開く・設定・カード追加 等）もパレットから実行可能にするか（今回含める / カード・盤面のみ）。
3. **既定/代替アクションの操作**: Enter=既定（コピー可ならコピー）＋ `Alt+Enter`=もう一方、にするか／各候補行に小ボタン（コピー・ジャンプ）を出すか。
4. **空入力時**の表示: 何も出さない / 全カードを一覧 / 簡単なヒント。
5. **開くキー**: `Ctrl+K` のみ？ `Ctrl+P` も割り当てるか。
