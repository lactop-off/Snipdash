# テーブルカード 設計書

> 対象: カード種別 `table`（schema v2 への追加）
> ステータス: **PoC 実装済み**（`feat: テーブルカード…` コミット）。本書は確定設計と実装の対応表を兼ねる。

## 1. 目的

表形式のデータ（接続先一覧・環境変数・定型値の対応表など）を 1 枚のカードに並べ、
**ボタンを置かずに、表示されているセルをクリックするだけでクリップボードへコピー**できるようにする。

「よく使う値をワンクリックで取り出す」という Snipdash の中核体験を、行×列の密度が高いデータにも広げる。

## 2. 決定事項（合意済み）

| 論点 | 決定 | 理由 |
|---|---|---|
| コピー単位 | **セルのみ** | 迷いがなく、ボタンレスのクリック操作と最も相性が良い |
| ヘッダー | **固定（先頭1行）** | 表として見やすく、列の意味が明確。ヘッダーはコピー対象外（ラベル）|
| 編集時の入力 | **TSV/CSV 貼り付け対応** | 表計算からの一括入力で初期データ投入が一瞬 |

## 3. データモデル

`Card` ユニオンに `table` を追加（`text | rich | spacer | table`）。`schemaVersion` は **2 のまま**（削除を伴わない追加のため後方互換）。

```ts
// @snipdash/sdk
export interface TablePayload {
  headers: string[];    // 固定ヘッダー。これが列定義も兼ねる（列数 = headers.length）
  rows: string[][];     // 各行は headers.length 個のセル値（normalizeTableRows で正規化）
}
export type TableCard = CardBase & { type: "table"; payload: TablePayload };
```

Rust 側（`snipdash-core`）も同形（`TableCard` / `TablePayload`、`#[serde(tag = "type")]` の `Table` バリアント）。

## 4. 操作仕様

### 4.1 使用モード（クリックでコピー）
- **本文セルをクリック** → そのセル値を**テンプレート変数展開**（`{{TODAY}}` 等）してコピー → トースト「コピーしました」＋セルが一瞬フラッシュ。
- **ホバー** → 背景ハイライト＋`cursor:pointer`＋右端にコピーアイコンをフェードイン（クリック可能の示唆）。
- **テキスト選択中**（`window.getSelection()` が非 collapsed）→ コピーを発火しない（部分選択を尊重）。
- **空セル** → 何もしない（トーストも出さない）。斜線ハッチで空であることを表示。
- **ヘッダーセル** → 列ラベル。コピー対象外。

### 4.2 編集モード
- ヘッダー／本文セルを**インライン編集**（`<input>`）。
- **列の追加/削除**（ヘッダーと全行を同時に調整、最低1列は維持）、**行の追加/削除**。
- **貼り付け一括入力**: セルに TSV/CSV を貼り付けると表全体を置換。**1行目＝ヘッダー / 2行目以降＝本文**。タブを含めば TSV、無ければカンマ区切りとして解釈。

## 5. 検証・正規化

- `snipdash-core::validate_card`: テーブルは **ヘッダーが最低1列** であること。
- `normalizeTableRows(headers, rows)`（SDK）: 各行を `headers.length` にパディング/トリムし、ガタつきを防止。描画・編集・貼り付けの各段で適用。

## 6. エッジケース

| ケース | 挙動 |
|---|---|
| 長い値 | セルは省略表示（`…`）＋ `title` で全文。**コピーは全文** |
| 列が多い/横に長い | カード内で横スクロール |
| 行ごとに列数が違う | ヘッダー数に正規化（パディング/トリム） |
| 空セルのクリック | 無視（コピーしない） |

## 7. 実装対応表

| 層 | ファイル | 変更 |
|---|---|---|
| core | `crates/snipdash-core/src/model.rs` | `Card::Table`＋`TableCard`/`TablePayload`、`id/layout/type_name` |
| core | `…/validate.rs` | テーブル検証（ヘッダー≥1） |
| core | `…/defaults.rs` | サンプル表（「接続先一覧」） |
| core | `…/lib.rs` | 直列化／検証テスト |
| sdk | `packages/snipdash-sdk/src/types.ts` | `TablePayload`/`TableCard`/`Card` |
| sdk | `…/factory.ts` | `createTableCard`・`copyableText`(=null)・`normalizeTableRows` |
| sdk | `…/search.ts` | テーブルを検索対象に（ヘッダー＋セル） |
| ui | `apps/desktop/src/components/TableCard.tsx` | 本体（使用/編集モード） |
| ui | `…/CardFrame.tsx` | ディスパッチに `table` を追加 |

| ui | `…/i18n.ts`, `styles.css`, `assets/icons/table.svg`, `sample.ts` | 文言・スタイル・アイコン・デモ |

> バックエンドの**新規 Tauri コマンドは不要**。コピーは既存の `copy_text`（`copyResolved`）を再利用する。

## 8. 検証結果（PoC）

- Rust core: **15 テスト pass**（テーブルの直列化・検証を含む）
- TS SDK: **19 テスト pass**
- フロント: 型チェック・Vite ビルド成功
- ヘッドレス Chromium で、**セルクリック→クリップボードに実値コピー**を確認（`db.prod.example:5432`）。使用/編集モードの描画も確認済み。

## 9. 今後の拡張候補（v2+）

- 行/列まるごとコピー（行番号・ヘッダークリック、区切りは TSV）— 今回は「セルのみ」で見送り。
- CSV のクオート（`"a,b"`）対応など貼り付けパーサの強化。
- 列幅の保存・整列（左/右/中央）・色タグ付きセル。
- 列単位のテンプレート（例: 列まるごとに接頭辞を付けてコピー）。

### 互換性メモ
`table` を含むワークスペースを**旧ビルドで開くと未知 type で読み込み失敗**しうる（前方互換は別課題）。schemaVersion は 2 のままで、新規追加は後方互換。
